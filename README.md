## 🚀 Projects

### Autonomous Maze Solver
A hackathon project focused on navigating an unknown maze with sensor inputs and limited actions. The solver maintains a map and internal memory, updates its position estimate, explores unknown areas, and uses breadth-first search (BFS) to plan routes through known paths.

**Concepts used:** Mapping, state/memory management, odometry-based position tracking, frontier exploration, and BFS path planning.

### DUM-E — Dynamic Unified Mentor Engine
A personal AI assistant project exploring voice interaction, computer vision, system automation, and local AI models. Hardware integration with Arduino and ESP32 is a future direction.
