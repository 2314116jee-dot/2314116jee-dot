## 🚀 Stuff I've Built

### 🤖 DUM-E — Dynamic Unified Mentor Engine
**Status: Completed ✅**

My personal AI assistant project, built to bring together voice interaction, study support, emotion detection, and PC automation. It also includes hardware integration using an **Arduino Uno**.

- 🎙️ Voice-based assistant and study support
- 🧠 Emotion-aware interaction
- 📚 Study tools such as learning support and study tracking
- 🖥️ Voice-based PC control and automation
- 🔌 Arduino Uno hardware integration

> DUM-E started as an idea for my own AI companion and became a hands-on project in connecting software, AI, and hardware.

### 🧭 Autonomous Maze Solver — Hackathon Project
An autonomous agent designed to navigate an unknown maze using sensor readings and a limited set of movement actions.

- 🗺️ Builds and updates an internal map of the maze
- 🧠 Uses memory to keep track of exploration and discovered paths
- 📍 Tracks estimated position and heading
- 🔎 Explores unknown areas instead of blindly repeating routes
- 🧮 Uses **Breadth-First Search (BFS)** to plan paths through known areas

**Concepts explored:** Mapping, odometry, state management, frontier exploration, and pathfinding.
